1. Review: Linear Dependence & Independence

Let $\{v_1, v_2, \dots, v_n\}$ be a set of $n$ vectors in a vector space $V$.

Linearly Dependent

There exist scalars $a_1, a_2, \dots, a_n$ not all zero such that:

$$a_1 v_1 + a_2 v_2 + \dots + a_n v_n = 0$$

In $\mathbb{R}^n$, the matrix system $Vx = 0$ has a non-trivial solution.

Linearly Independent

The only choice of scalars satisfying

$$a_1 v_1 + a_2 v_2 + \dots + a_n v_n = 0$$

is $a_1 = a_2 = \dots = a_n = 0$. Thus, $Vx = 0$ has only the trivial zero solution.

2. Span of a Set of Vectors

Definition (Span): The span of a set $S$ of vectors, denoted $\text{span}(S)$, is the set of all finite linear combinations of vectors in $S$: $$\text{span}(S) = \left\{ \sum_{i=1}^{k} a_i v_i \;\middle|\; v_i \in S, \; a_i \in \mathbb{R} \right\}$$

Key Property: $\text{span}(S)$ is always a subspace of $V$ (it contains the $0$ vector and is closed under linear combinations).

Geometric Examples

  • Single vector in $\mathbb{R}^2$: If $S = \{(1, 0)\}$, then $\text{span}(S) = \{(a, 0) \mid a \in \mathbb{R}\}$, which is the x-axis.
  • Diagonal line in $\mathbb{R}^2$: If $S = \{(1, 1)\}$, then $\text{span}(S) = \{(a, a) \mid a \in \mathbb{R}\}$, which is the line $y = x$.
  • Plane in $\mathbb{R}^3$: If $S = \{(1, 0, 0), (0, 1, 0)\}$, then $\text{span}(S) = \{(a, b, 0) \mid a, b \in \mathbb{R}\}$, which is the xy-plane.

3. Spanning Sets & Building by Appending

A set $S \subseteq V$ is a spanning set for $V$ if $\text{span}(S) = V$ (every vector in $V$ can be written as a linear combination of vectors in $S$).

  • If $T \subseteq S$, then $\text{span}(T) \subseteq \text{span}(S)$. Every superset of a spanning set is also a spanning set.
  • By convention (empty linear combination), $\text{span}(\emptyset) = \{0\}$.

Iterative Construction in $\mathbb{R}^3$ (Appending Outside the Span)

  1. Step 0: $S_0 = \emptyset \implies \text{span}(S_0) = \{(0,0,0)\}$ (Origin).
  2. Step 1: Pick $(0,2,1) \notin \text{span}(S_0) \implies S_1 = \{(0,2,1)\}$ (Spans a 1D line).
  3. Step 2: Pick $(2,2,0) \notin \text{span}(S_1) \implies S_2 = \{(0,2,1), (2,2,0)\}$ (Spans a 2D plane).
  4. Step 3: Pick $(0,0,5) \notin \text{span}(S_2) \implies S_3 = \{(0,2,1), (2,2,0), (0,0,5)\}$ (Spans all of $\mathbb{R}^3$).
For any $(x, y, z) \in \mathbb{R}^3$: $$(x, y, z) = \left(\frac{y - x}{2}\right)(0, 2, 1) + \left(\frac{x}{2}\right)(2, 2, 0) + \left(\frac{x - y + 2z}{10}\right)(0, 0, 5)$$

4. Basis of a Vector Space

Definition (Basis): A subset $B \subseteq V$ is a basis of $V$ if:
  1. $B$ is linearly independent, and
  2. $B$ spans $V$ ($\text{span}(B) = V$).

The Optimal Balance: A spanning set must be large enough to generate every vector in $V$, while a linearly independent set in $\mathbb{R}^n$ can have at most $n$ vectors. A basis hits the exact sweet spot.

The Standard Basis for $\mathbb{R}^n$

Let $e_i$ be the vector with $1$ in the $i$-th coordinate and $0$ everywhere else. Then $E = \{e_1, e_2, \dots, e_n\}$ is the standard basis for $\mathbb{R}^n$ because any $x = (x_1, \dots, x_n)$ is uniquely written as $x = \sum_{i=1}^n x_i e_i$.
